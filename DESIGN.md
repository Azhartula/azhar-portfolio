# DESIGN.md

## Direction (unslop + impeccable)
- **Product.** Portfolio that proves Azhar ships production AI systems.
- **Character.** Exact, instrument-like, quietly confident.
- **World.** Night-desk instruments — signal traces, adaptive routing boards, cool lab paper. Not SaaS purple, not cream terracotta.
- **Moments.** Hero name + signal ticks; right-side instrument panel (method / voice / vision readout). Project titles carry weight.
- **Signature.** Thin frequency ticks under the wordmark and primary CTA underline.

## Tokens
- **Ramp:** darker beige — bg `#cfc4b0`, raised `#c2b59e`, panel `#ddd2bf`, text `#1a1611` / `#4a4338` / `#6a6154`
- **Accent:** bronze `#7a5530` (rare: primary hover, signature ticks, active link)
- **Type:** IBM Plex Sans (UI) + IBM Plex Mono (meta/figures). Display name uses Plex Sans at large size, weight 500
- **Radius:** controls 8px, panels 12px — no pills
- **Spacing:** 4px grid; section gaps 64–96
- **Motion:** one short fade-rise on hero only; elsewhere color/opacity transitions ~150ms

## Anti-patterns removed
Cream wash, terracotta accent, grid overlay, ALL-CAPS eyebrows, section indices, pill CTAs, arrow-affixed links, radial color blobs.
