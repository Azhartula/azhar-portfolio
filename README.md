# Azhar Iqbal — Portfolio

React + Vite portfolio site.

**GitHub:** https://github.com/Azhartula/azhar-portfolio

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy on Vercel (free)

1. Import https://github.com/Azhartula/azhar-portfolio in [Vercel](https://vercel.com/new)
2. Framework: Vite · Build: `npm run build` · Output: `dist`
3. Deploy — you get a free `*.vercel.app` URL

Or from this folder: `npx vercel`

## Content

Edit `src/data.ts` for copy, links, and sections. Styles live in `src/index.css`.

**Note:** Confirm the LinkedIn URL in `src/data.ts` matches your real profile.
